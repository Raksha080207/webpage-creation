# HRV Horizons Academy

HRV Horizons Academy is a school website designed to provide students and parents with an easy way to explore the school and its facilities.

The website includes information about academic programs, infrastructure, facilities, food menus, admissions, fee details, and parent feedback.

Built with HTML, CSS, and Bootstrap 5.3, the website focuses on creating a friendly, attractive, and user-friendly experience.

## Features
- Home page
- Academic programs and catalogue
- Admission and enrollment details
- Infrastructure and facilities
- Food menu
- Parent feedback and reviews

## Technologies Used
- HTML
- CSS
- Bootstrap 5.3

## Project Goal
To make important school-related information easily accessible to students and parents through a simple and engaging website.
